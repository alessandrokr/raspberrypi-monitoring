# Raspberry Pi Monitoring
Monitor your Pi.

🔨 Usage:
Prerequisites: python 3.x, raspberrypi 3<
- clone into your home-directory: `git clone https://github.com/alessandrokr/raspberrypi-monitoring.git`
- create python venv inside the raspberrypi-monitoring directory: `python -m venv .`
- activate the virtual environment: `source bin/activate`
- install requirements: `pip install -r requirements.txt`

🛠️ Features:
- Web UI
- Hardware monitoring
- Configure your PI and the Web Interface

👀 Monitoring:
- CPU Temperature
- Whether the Pi is being throttled
- SD card usage
